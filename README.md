# jcode-ru

Русифицированный форк [jcode](https://github.com/1jehuang/jcode) — быстрого терминального AI-агента для кодинга на Rust.

> **Неофициальный форк.** Проект не связан с разработчиками оригинального jcode и не поддерживается ими. Весь оригинальный код принадлежит его авторам и распространяется под лицензией [MIT](LICENSE). Здесь публикуется только сборка с частичной русской локализацией интерфейса.

Оригинальный README апстрима сохранён в [README.upstream.md](README.upstream.md).

---

## Что добавлено к оригиналу

- **Частичная русская локализация TUI** — переведены пользовательские строки интерфейса:
  - справка и описания слэш-команд;
  - экраны входа и управления аккаунтами (login/account pickers);
  - статус-уведомления и сообщения в интерфейсе;
  - онбординг (мастер первоначальной настройки);
  - оверлеи, подсказки ввода и футер.
- Литералы, используемые как **ключи парсинга** (`match`-паттерны, сравнения, `starts_with`/`contains` и т.п.), намеренно оставлены на английском — иначе ломается разбор пользовательских команд.

## Скачать

Локальная сборка: `dist/jcode_0.84.0-ru.0001_amd64.deb`

Пакет ставит бинарник в `/usr/bin/jcode`.

## Установка

```bash
sudo dpkg -i dist/jcode_0.84.0-ru.0001_amd64.deb
jcode --version
```

## Сборка из исходников

Требуется Rust stable (edition 2024). Сборка идёт из checkout без каталога `assets/`
(тяжёлые демо-ролики исключены через sparse-checkout).

```bash
# Обычная сборка (нужен libssl-dev для native-tls):
cargo build --release --bin jcode

# Если libssl-dev не установлен — встроенный OpenSSL:
cargo build --release --bin jcode --features linux-compat-vendored-openssl
```

Сборка `.deb`:

```bash
JCODE_DEB_VERSION=0.84.0-ru.0001 scripts/make_deb_ru.sh
```

## Статус локализации

- Переведено около **2 762 строк** в **63 файлах** (`crates/jcode-tui`, `crates/jcode-tui-account-picker`).
- Около **1 485 строк** пропущены как служебные (логи, ключи конфигов, идентификаторы).
- Часть справки и отдельные строки пока остаются на английском.
- CLI-справка `jcode --help` (генерируется clap в крейте `jcode`) пока не локализована.
